Organiser son développement professionnel

Contexte : Bilan d'apprentissage du stage et mise en place d'une veille technologique.

1. Bilan d'apprentissage et auto-formation

Acquisitions techniques : Progression sur la rédaction de scripts PowerShell, l'écriture de requêtes SQL complexes (jointures, sous-requêtes NOT EXISTS) et l'administration de bases de données.

Progrès méthodologiques : Amélioration de l'autonomie sur environnement de test, structuration du code et meilleure gestion de la documentation technique.

2. Dispositif de Veille Technologique : L'AIOps

Thématique retenue : L'intégration de l'Intelligence Artificielle dans l'automatisation et la supervision des infrastructures informatiques (AIOps).

Méthodologie de collecte :

  • Configuration d'un agrégateur de flux RSS (Feedly) ciblant les actualités AIOps, PowerShell et SQL Server.
  • Mise en place de Google Alerts sur les mots-clés : AIOps automation, Database supervision AI, SQL Server automation.
  • Consultation régulière des blogs techniques spécialisés (Microsoft Learn, Developpez.com).
