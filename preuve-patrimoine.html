Activité 4 : Audit et correction de bases de données (Affaires à risque)

Cahier des charges : Le groupe utilise l'ERP Espace Affaire pour gérer les devis, commandes et factures. Avant de nettoyer l'environnement de test de la filiale BASC CI ELEC, l'objectif était de comparer deux bases de données (EA_FLEX et EA_FLEX_OLD) pour détecter les écarts et les corriger[cite: 8].

Démarche et mode opératoire :

  • Comptage du nombre de lignes pour chaque table afin d'isoler les tables présentant des différences d'effectifs.
  • Écriture de requêtes d'audit SQL sous SQL Server Management Studio avec des clauses LEFT JOIN et NOT EXISTS (notamment sur les tables M_FIELD et M_FILE)[cite: 8].
  • Génération et exécution de scripts INSERT pour réintégrer les enregistrements manquants et garantir la parité des deux bases.
-- Exemple de requête de comptage et comparaison d'écart DECLARE @SourceDB SYSNAME = 'EA_FLEX'; DECLARE @TargetDB SYSNAME = 'EA_FLEX_OLD'; SELECT * FROM EA_FLEX_OLD.dbo.M_FIELD A WHERE NOT EXISTS ( SELECT 1 FROM EA_FLEX.dbo.M_FIELD B WHERE B.ID = A.ID );

Explication pour l'oral :

« Lors de cette mission, j'ai vérifié l'intégrité des données entre deux bases de données de l'ERP Espace Affaire. En utilisant des requêtes SQL avancées avec la clause NOT EXISTS, j'ai identifié précisément les lignes absentes dans la base cible puis j'ai rédigé des scripts d'insertion SQL pour réaligner parfaitement les données avant nettoyage du serveur[cite: 8]. »

Activité 5 : Matrice des droits d'accès Active Directory

Cahier des charges : Pour des motifs de sécurité et de conformité, la DSID devait connaître avec précision la répartition des permissions accordées sur les dossiers partagés des serveurs de fichiers pour chaque filiale du groupe[cite: 8].

Démarche et mode opératoire :

  • Exploitation d'un export brut répertoriant les groupes Active Directory affectés aux dossiers partagés.
  • Participation à la conception d'une macro VBA Excel analysant la nomenclature des groupes (reconnaissance des suffixes _RW pour Lecture/Écriture et _RD pour Lecture seule).
  • Application automatique d'un code couleur : vert pour la lecture/écriture, jaune pour la lecture seule, et blanc en l'absence d'accès.
  • Rdaction d'une procédure d'utilisation synthétique à destination des techniciens de la DSID pour réexécuter le traitement à la demande.

Explication pour l'oral :

« Pour rendre lisible la gestion des habilitations sur les serveurs de fichiers, j'ai contribué au développement d'une macro VBA générique. Le script parcourt la liste des groupes Active Directory, identifie les droits à partir de leurs suffixes (_RW / _RD) et génère une matrice visuelle avec mise en forme conditionnelle automatique[cite: 8]. J'ai également rédigé la documentation technique[cite: 8]. »
