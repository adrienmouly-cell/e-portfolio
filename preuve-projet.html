Activité 1 : Application web FAQ — Maison des Ligues (M2L)

Cahier des charges : Conception et réalisation en équipe de 5 étudiants d'une plateforme centralisée de foire aux questions pour les membres et responsables de ligues sportives, intégrant une gestion stricte des droits (Visiteur, Admin Ligue, Super Admin).

Démarche et mode opératoire :

  • Répartition des rôles au sein du groupe (conception BDD, maquettage IHM, authentification, modération et conteneurisation).
  • Modélisation conceptuelle, logique et physique de la base de données (MCD, MLD, MPD) et élaboration du Diagramme de Cas d'Utilisation (DCU) sous Draw.io.
  • Développement collaboratif de l'application en PHP/MySQL avec architecture modulaire et requêtes préparées (PDO).
  • Sécurisation des accès (hachage `password_hash()`, protection contre les failles XSS) et déploiement sous Docker Compose.

Activité 2 : Mini-projet base de données (SQL Server et PowerShell)

Cahier des charges : Concevoir une base de données de test sur le serveur SRV-SQLEAF-LAB (base MINIPROJET) et développer des scripts PowerShell autonomes capables d'interroger la base et d'exporter les résultats pour les métiers sans accès direct à SQL Server.

Démarche et mode opératoire :

  • Conception des tables Employes et Services sous SQL Server avec clés primaires/étrangères et jeu de données de test.
  • Rédaction de scripts PowerShell intégrant la commande Invoke-Sqlcmd pour exécuter des requêtes dynamiques basées sur une saisie utilisateur (ex : choix du service).
  • Mise en place de calculs statistiques automatisés (nombre d'employés, masse salariale, salaire moyen via COUNT, AVG, MAX).
  • Automatisation de l'extraction des données brutes vers des fichiers d'échange au format CSV (Export-Csv).
# Script PowerShell d'extraction dynamique $server = "SRV-SQLEAF-LAB" $database = "MINIPROJET" $service = Read-Host "Entrez le nom du service" $query = "SELECT * FROM Employes WHERE Service = '$service'" Invoke-Sqlcmd -ServerInstance $server -Database $database -Query $query | Export-Csv -Path "C:\Exports\$service.csv" -NoTypeInformation
